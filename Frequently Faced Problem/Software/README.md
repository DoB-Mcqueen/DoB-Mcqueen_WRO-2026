# Software & ROS2 Problems

#### Sensor Fusion Drift in Real-Time Odometry: Cumulative mathematical positioning errors when combining wheel encoder ticks with noisy IMU data over extended runs.

#### Node Communication Latency & Message Drops: Network delays or high CPU usage on the single-board computer slowing down the publish/subscribe rate between image processing nodes and control loops.

#### Exposure and Lighting Variances in Color Detection: Ambient lighting shifts changing the camera's hex color tracking threshold data, causing target towers to become invisible to the vision nodes.

#### LiDAR Data Noise & Ghost Obstacles: Reflection anomalies off highly reflective track border surfaces causing false positive obstacle detections in navigation loops.

#### URDF Kinematic Mismatch in Simulation Workstations: Discrepancies between the virtualized physical parameters in Gazebo and the actual friction, slip, and weight balance of the real robot hardware.
